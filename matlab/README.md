# CMM Normal-Deviation Correction: Four-Parameter Robust MATLAB Pipeline

MATLAB research software for four-parameter normal-deviation fitting, Huber IRLS correction and before/after diagnostic metrics for circular or spherical CMM point sets. It does not implement the missing seven-parameter angular research module, a complete volumetric compensation map or an ISO acceptance test.
